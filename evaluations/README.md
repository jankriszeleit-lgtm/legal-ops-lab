# Evaluations

This directory is reserved for public evaluations that are useful, reproducible and safe to share.

Evaluations are optional. They should be published only when the underlying material can be disclosed responsibly.

## Minimum evaluation record

A useful evaluation should identify:

- artifact/release tested;
- test ID;
- input;
- expected behaviour;
- observed behaviour;
- evidence;
- PASS / FAIL / UNVERIFIED;
- limitations.

Do not publish client data, privileged material or unverifiable reconstructed evidence.

A published evaluation is evidence about the tested release and test conditions, not a general claim that a method or prompt is universally reliable.
